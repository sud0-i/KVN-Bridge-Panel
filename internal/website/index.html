Plain Web Notes

Short, practical notes on making small websites.

Start with what the reader needs

Give each page one job. Put its main answer near the top, use headings that describe what follows, and label links with their destination.

Let the page fit the screen

Keep long passages to a comfortable width and let the layout shrink on smaller screens. Read the page on a phone and try it with the text enlarged.

Keep a copy you can restore

Save the source and any images together. Before changing hosts, open the copy on a different machine to catch any files or links you missed.
